# node-lab-website

A responsive band website developed for **Laboratory Work 1** in the university course **Web Application Development Tools**. The project uses Express.js to serve a static website based on a university-provided W3.CSS template, extended with custom styling and interactive JavaScript features.

## Technologies

- **Node.js** — JavaScript runtime for the local server.
- **Express.js** — serves static files from the `express` directory on port 3000.
- **HTML5** — website structure and content.
- **CSS3** — custom styling, hover effects, themes, and animations.
- **JavaScript** — slideshow, navigation, modal controls, and interactive effects.
- **W3.CSS** — responsive layout and interface components.

The page also loads the Lato font through Google Fonts, Font Awesome icons, and images hosted by W3Schools.

## Website Features

- **Automatic slideshow:** cycles through concert images every four seconds.
- **Responsive navigation:** section links, a dropdown menu, and a collapsible mobile menu.
- **Ticket modal:** opens from tour card buttons and closes using its close controls or by clicking outside the dialog.
- **Custom CSS (Task 5):** navy, white, and blue colors; readable paragraphs; styled list items; rounded images; improved navigation and tour cards; and smooth hover effects.
- **Dark mode (Task 6):** switches between light and dark themes.
- **Like counter (Task 6):** increments with each click and displays a special message when five likes are reached.
- **Show/hide information (Task 6):** toggles additional information in the Fan Zone.
- **Fade-in animation (Task 6):** uses `IntersectionObserver` to animate the Fan Zone when it enters the viewport, respecting reduced-motion preferences.
- **Contact section:** displays contact details and the template's contact form.

Theme selection and likes are stored only in the current page session and reset on reload. The ticket and contact forms are interface demonstrations; the Express server does not implement booking, payment, or contact submission endpoints.

## Project Structure

```text
node-lab-website/
├── express/
│   └── index.html       # Website HTML, custom CSS, and JavaScript
├── .gitignore          # Excludes dependencies, IDE files, and .env
├── package.json        # Project metadata, dependencies, and npm scripts
├── package-lock.json   # Dependency lockfile
├── README.md           # Project documentation
└── server.js           # Express static server
```

The `node_modules/` directory is generated by `npm install` and is excluded from version control.

## Installation

Install Node.js and npm, then clone or download this repository. Open a terminal in the `node-lab-website` directory and run:

```sh
npm install
```

## Running the Project

From the project directory, start the server:

```sh
npm start
```

Open **[http://localhost:3000](http://localhost:3000)** in your browser.

Press `Ctrl+C` in the terminal to stop the server. If PowerShell blocks `npm.ps1`, use `npm.cmd install` and `npm.cmd start` instead.

An internet connection is needed to load the externally hosted W3.CSS stylesheet, fonts, icons, and images.

## Trying the Interactive Features

1. Watch the slideshow and use the navigation links to explore the page.
2. Select **Buy Tickets** on a tour card to open the ticket modal.
3. Scroll below Contact to the **Fan Zone** to see its fade-in animation.
4. Select **Dark mode: off** to enable dark mode; select it again to restore light mode.
5. Select **Like the band** five times to see the milestone message.
6. Select **Show information**, then **Hide information**, to test the visibility toggle.
